# 对象信息与轴点 · SketchUp

实时查看组／组件信息，编辑世界与父级坐标移动物体，按步长微调，并通过包围框 15 个点位原位修改轴点。

**版本：1.1.0 · 验证环境：SketchUp 2024 / Windows · 许可证：AGPL-3.0-only**

[下载 RBZ 安装包](https://github.com/leolee9086/sketchup-axis-inspector/releases/latest) · [更新记录](CHANGELOG.md) · [测试与构建](TESTING.md)

## 安装与打开

在「扩展程序 → 扩展管理器 → 安装扩展程序」选择 RBZ。通过工具栏、扩展菜单的「对象信息与轴点」，或单选组／组件后的右键菜单打开面板。保持面板开启，切换选择会自动更新。

不依赖“移入内部”、外部服务或网络。使用 SketchUp Overlay，因此要求 SketchUp 2023 或更高版本；目前实际验收环境为 Windows SketchUp 2024。

## 按坐标移动整个物体

面板同时显示并可编辑：

- **世界坐标**：轴点相对模型世界原点的坐标，与绘图轴的显示位置无关。
- **父级坐标**：轴点相对直接父级组／组件的坐标。根层级对象的两套坐标相同。

编辑 X/Y/Z 后按 **Enter** 或点「应用」。对象位置改变，朝向、尺寸和内部结构保持。**Esc** 还原尚未应用的输入。

统一显示毫米，无单位数字按毫米解释，也可输入 `25cm`、`1.2m`、`1in`、`1ft`。世界坐标使用完整变换求逆，支持旋转、镜像、非均匀缩放的父级。

### 箭头步进与常用模数

每个 X/Y/Z 旁有 **▲ / ▼**，分别增加／减少一个步长。输入框获得焦点时，也可用键盘 **↑ / ↓** 单次步进。

- 步长可以直接输入正数及单位，例如 `0.5`、`18mm`、`3.2cm`。
- 尺寸系列提供快捷值：

| 系列 | 常用步长，单位 mm |
| --- | --- |
| 精调／缝隙 | 0.1、0.5、1、2、3、5、10、20 |
| 建筑模数，M = 100 mm | 50、100、200、300、600、1200、3000、6000 |
| 柜体／五金 32 mm 系列 | 16、32、64、96、128、160、192、224、256、320 |
| 常用板厚／材料 | 3、5、9、12、15、18、20、25、30、36 |
| 铺贴／吊顶常用尺寸 | 100、150、200、300、400、450、600、800、900、1200 |

这些是建模快捷预设，不是强制规范；实际工程尺寸以图纸和产品资料为准。切换系列只换快捷按钮，不会移动物体；点击某个预设只改变步长。

箭头从**模型的全精度坐标**计算相对位移，不吸附网格，不拿显示舍入值反复累加。世界步长沿世界轴；父级步长沿直接父级坐标轴，继承父级缩放。

有未应用的坐标草稿时，箭头提示先应用或还原，不会悄悄提交或覆盖输入。每次移动均可 **Ctrl+Z** 一步撤销；支持原生重做。

坐标移动只改当前实例。若对象位于共享父组件内，必要的父路径会独立化；目标组件本身的定义关联保持。

## 原位修改轴点

提供 **8 个角点、6 个面心、1 个中心**：

- 悬停图示或按钮，显示目标世界坐标，并在模型视图预览候选轴点。
- 点击点位，**只改变轴点，物体保持原位，轴方向不改变**。
- 图示空白处可拖动旋转；文字按钮可访问被遮住的点位。
- 包围框沿对象**局部轴**计算；薄构件的示意厚度会放大，精确尺寸以读数为准。
- 「模型预览」可关闭 Overlay。预览不替换选择／轨道工具。

默认「仅当前实例」，必要时独立化共享父路径及目标。也可选择所有同定义实例联动改轴，执行前确认；全部实例的几何仍保持原位。

## 信息与限制

显示类型、名称、定义、ID、所属路径、标签、材质、实体状态、体积、锁定／隐藏、内部实体数、同定义直接实例数，以及轴点坐标、沿局部轴的实际尺寸、定义尺寸、世界包围框、累计缩放、世界轴方向和镜像状态。尺寸顺序均为 X/Y/Z。实例数是直接定义引用数，不是嵌套展开后的出现总数。

- 单选组／组件有效；多选和散几何不执行移动。
- 锁定对象／祖先、粘接关系、不可逆坐标变换会拒绝对应操作。
- 空对象可查看和编辑位置，但没有包围框快捷点。
- 开洞组件不支持原位改轴，其切口依赖轴定义。
- 动态组件后续重绘可能重新计算内部坐标；面板提示此边界。第三方对局部坐标的绑定不在保证范围内。
- 不炸开或重建目标实例。共享父级独立化时，内部实体由 SketchUp 原生克隆，内部 ID 可能改变。
- 不自动保存模型。仅主动点击「复制对象信息」时写入剪贴板。
- 面板随选择、事务、撤销／重做、编辑路径变化更新；过期请求不会应用到新对象。

兼容已核实的痞子库／云管理器接管环境，仅对本扩展的注册及工具栏显示调用原生入口，不修改全局方法或其他插件设置。
